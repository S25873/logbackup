백업 도우미 — 정리

* 삭제 · 남은 별표를 모두 지워요.

“ ” → " " · 휜 큰따옴표(“ ”)를 곧은 큰따옴표(")로 바꿔요.

‘ ’ → ' ' · 휜 작은따옴표(‘ ’)를 곧은 작은따옴표(')로 바꿔요.

... → ⋯ · 마침표 3개 이상과 … 을 ⋯ 로 바꿔요.

<br> <sub> 삭제 · 본문에 글자로 남은 <br>·<sub>·</sub> 태그를 지워요.

따옴표 넣기 · 앞뒤 글자가 * ( ) 따옴표가 아닌 줄을 통째로 " " 로 감싸요. (지문 *…*·번역 (…)·이미 따옴표 붙은 줄은 건너뜀)

백업 도우미 — 서식

*색* · *…* 로 감싼 부분을 지금 고른 강조색으로 칠해요(별표 포함).

"색" · "…" 로 감싼 부분을 따옴표째 강조색으로 칠해요.

(이탤릭) · (…) 로 감싼 부분을 괄호째 기울여요.

강조색 18개 · 글자를 드래그해 색을 고르거나, 이미 색칠된 곳에 커서만 둔 채 다른 번호를 누르면 그 색으로 바뀌어요. 서식 지우기는 선택 영역이나 커서가 놓인 색/기울임을 해제해요.

HTML 복사 · 색·기울임은 인라인 style로, 줄바꿈은 <br>로 바뀌어 티스토리 HTML 모드에 붙여넣으면 그대로 나와요.

입력 도우미

외국어·한국어 칸의 같은 줄끼리 짝지어 "외국어"<br>(한국어) 로 만들어요. 한쪽만 있으면 그쪽만 나와요.
